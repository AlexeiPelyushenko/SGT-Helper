This repository is a simple program to help with studying spectral graph theory. In reality you could use it for any topic but that's why I made it.

Features:
- Can write in LaTeX
- Add/delete topics
- Add/read/edit/delete information associated with topics
- Data gets saved between sessions

Feel free to clone it. If you want to contribute to the repo either by information in info.json or by improving the program itself let me know, it'd be much appreciated.
